# November 3 checkpoint addendum — Zoo UCMS

Decision: create Philadelphia Zoo Unified Content Management System as a third standalone project alongside the Mapping App and ASIS. Six initial departmental content areas: Conservation Education, Animal Care, Marketing, Public Relations, Visitor Services, and IT. All use a consistent role-based dashboard. IT has distinct platform administration and employee-content responsibilities. Visitor Services is in initial scope, including amenities, accessibility and restroom reports. The CMS supplies approved shared information via APIs to both applications; sensitive animal tracking remains in ASIS. Separate public and employee channels; authorize restricted GIS layers by role. Include approvals, scheduling, audit history and emergency precedence. User will open a dedicated CMS project thread. This addendum records planning, not implementation.
